# conf

A sandbox for brainstorming and exploring ideas before they're worth a real,
dedicated project.

Each idea lives in its own folder under `explorations/`, as a self-contained
prototype — rough, disposable, not held to the bar of production code. When
one earns its own dedicated repo, it moves out of here.

## Explorations

- [`explorations/urlpeek`](explorations/urlpeek) — CLI to preview a URL
  (metadata, heuristic risk checks, sandboxed screenshot) before opening it
  in a real browser.
- [`explorations/drivefind`](explorations/drivefind) — AI-powered semantic
  search over Google Drive: per-file descriptions/tags/subtitles generated
  by Claude, embedded with Voyage AI, searchable and downloadable from a
  local web UI.
